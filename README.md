# Elreen's Toolbox VPM

Public VCC repository for the Elreen's Toolbox installer.

- Install page: <https://elreen.github.io/vpm/>
- VPM listing: <https://elreen.github.io/vpm/index.json>

The package in this repository is the public installer. A valid Jinxxy license is required before it downloads the protected Toolbox package into a Unity project.
