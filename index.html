ELREEN'S TOOLBOX

Install with VCC

Install the public VCC package first. After your Jinxxy license has been verified, the complete Toolbox is downloaded directly into your Unity project.

Add to VCC Repository JSON
https://elreen.github.io/vpm/index.json
  1. Add this repository to VCC.
  2. Select Manage Project for your Unity project.
  3. Add Elreen's Toolbox Installer.
  4. In Unity, open Tools → Elreen's Toolbox Installer and activate the Toolbox once.
Installer updates appear in VCC. Toolbox updates are checked from the installer window in Unity.
